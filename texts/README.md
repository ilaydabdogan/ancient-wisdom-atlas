# Texts

This directory holds complete Markdown source texts.

Use:

- `public-domain/` for verified public-domain editions and translations
- `open-license/` for CC BY, CC BY-SA, and compatible open-license texts
- `permissioned/` for texts included under explicit permission
- `citation-only/` for works that should not be hosted in full

Each full text must use `templates/full-text.md` and must include copyright/license metadata plus separate trademark metadata.

The target state is: complete source texts here, interpretation in `patterns/`, motif definitions in `taxonomy/`, and source registry metadata in `data/sources/`.
