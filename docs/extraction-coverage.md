## Status Logic

- `no_extractions`: no passage-level extraction records exist yet.
- `thin`: records exist, but coverage is far below the rough target or motif count is very small.
- `developing`: meaningful coverage exists, but more passage coverage is still needed.
- `dense_draft`: extraction density is acceptable, but records still need review or normalization.
- `dense_reviewed`: extraction density is acceptable and records are marked reviewed.

The target is intentionally rough: about one extraction record per 4,000 words, with a minimum of two and a cap of forty per text. It is a planning signal, not a scholarly claim.

## Batch Targeting

Build the latest coverage index:

```sh
ruby scripts/build_extraction_coverage.rb
```

Prepare passage segmentation only for high-priority texts:

```sh
ruby scripts/batch_segment_passages.rb \
  --run-id motif-extraction-YYYY-MM-DD-high-priority \
  --coverage data/indexes/extraction-coverage.yml \
  --coverage-priority high \
  --force
```

Then prepare motif extraction requests from those passages:

```sh
ruby scripts/batch_prepare_motif_requests.rb \
  --run-id motif-extraction-YYYY-MM-DD-high-priority \
  --model "$OPENAI_BATCH_MODEL" \
  --max-output-tokens 12000 \
  --force
```
