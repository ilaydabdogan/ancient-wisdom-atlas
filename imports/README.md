# Imports Workspace

This directory is for temporary ingestion work only.

Use:

- `imports/raw/` for downloaded HTML, TXT, EPUB, XML, OCR, or scraped source material
- `imports/converted/` for intermediate Markdown produced by conversion tools

Both directories are ignored by Git. Canonical corpus files belong only in `texts/` after rights review, cleanup, metadata, and validation.

Do not commit raw downloaded pages, scraped HTML, OCR dumps, or intermediate converter output.
